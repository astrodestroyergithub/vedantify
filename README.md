# 🕉️ Vedantify — Netlify Production Bundle

**Vedantify** is a responsive, fault-tolerant web platform dedicated to the Vedas, Upanishads, Itihasas (Ramayana & Mahabharata), Metacognition (Sakshi Bhava), Gamified Child Moral Education (Bal Sanskar), Sanatana Dharma News, Community Service (Vishwa Seva), and the Year-Round Hindu Festival Calendar & Advance Planner.

## 🚀 Instant Netlify Deployment (2 Ways)

1. **Netlify Drop (30 Seconds)**:
   - Go to [https://app.netlify.com/drop](https://app.netlify.com/drop)
   - Drag and drop this unzipped `vedantify-netlify` folder directly onto the page.
   - Your site is live with HTTPS, CDN caching, and SPA routing via `netlify.toml` and `_redirects`.

2. **Git CI/CD Deployment**:
   - Push this folder to a GitHub/GitLab repository.
   - Connect the repository in Netlify (`Publish directory: .`, no build command needed).
